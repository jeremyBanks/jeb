# Usage

## [stadia.run](https://stadia.run)

[`https://stadia.run`](https://stadia.run) will display all games available on Stadia.

[`https://stadia.run/game-name`](https://stadia.run/game-name) will launch the named game if the name if an exact match or the only partial match.

[`https://stadia.run/?q=partial-game-name`](https://stadia.run/?q=game-name) will display all games matching the query.

[`https://stadia.run/#dev-tools`](https://stadia.run/#dev-tools) is for me.
