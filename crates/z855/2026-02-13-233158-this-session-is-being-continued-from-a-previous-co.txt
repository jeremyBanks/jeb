⏺ Now to your question about larger fallbacks:

  The fallback chain is:
  8+ (|) → 7 (~) → 6 (_) → 5 (;) → 4 block-aligned (,) → 4 non-aligned (,) →
  standard Z85

  Where bit-reversal applies:
  - 8+ (|): No position variance - always uses entire safe run (up to 64KB). No
  ranking needed.
  - 7/6/5 bytes: Each size has bit-reversal ranking across positions 0-3 ✓
  - 4-byte non-aligned: Now has bit-reversal ranking across positions 1-3 ✓

  The key nuance you asked about:
  When falling from 7→6→5, the position P determines which subsection is used
  (P=0 uses bytes 0-K, P=1 uses bytes 1 to K+1, etc.). Bit-reversal ranking is
  applied within each size tier, so we try the best-aligned position for 7-byte
  first, and only if ALL 7-byte positions fail do we move to 6-byte and rank
  those positions.
